# Rollback: 20261103100000_fiscal_okc

Adds `orders.settlement_source`, `restaurant_fiscal_settings`, `fiscal_documents`, two triggers
(`fiscal_orders_changed` on orders, `fiscal_session_closed` on table_sessions) and the ÖKC worker
functions. Nothing happens until a restaurant has an enabled row in `restaurant_fiscal_settings`.

Down migrations are not used; fix forward. To stop the integration immediately:
`update public.restaurant_fiscal_settings set enabled = false;` and, if the worker was configured,
`select cron.unschedule('fiscal-sync-worker-every-minute');`. Orders already settled by a device
keep `settlement_source = 'okc'` and stay paid. To remove the feature, drop the two triggers, the
functions, the two tables and the column, after the dashboard code is reverted.
